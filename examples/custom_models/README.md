# Example custom YOLO model

This directory contains an example user-trained Ultralytics YOLOv12 model provided for demonstrating the Custom Model functionality of the YOLO-MOD plugin described in the accompanying SoftwareX article.

Object classes:
- Plane
- Bridge
- Airport
- Harbor
- Vehicle
- Ship
  
## Files

- `yolo12m_demo.pt` – example user-trained Ultralytics YOLOv12 model corresponding to the interface shown in Fig. 2(a) of the accompanying SoftwareX article.
